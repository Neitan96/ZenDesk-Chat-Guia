Fundamentos da plataforma

AI Agent

ATUAL

Nome atual da linha de chatbot/IA do Zendesk. Substituiu Answer Bot e o Bot Builder clássico.

EAP

ATENÇÃO

Early Access Program. Recurso ainda não disponível por padrão em toda conta.

Insights Dashboard

ATUAL

Painel de métricas básico, incluso em qualquer plano: volume, resolução, escalonamento.

Construindo o agente

Use case

O assunto que o agente sabe resolver, como "consultar status de pedido".

Intent

Como o sistema reconhece qual use case o cliente quer, a partir do que ele digitou.

Dialogue

Fluxo guiado, desenhado em árvore de decisão no Dialogue Builder.

Generative procedure

Resposta gerada por IA a partir de um procedimento em linguagem natural + base de conhecimento.

Procedure map

Visualização automática dos passos da procedure. Revise antes de publicar.

Variável

Container de dado da conversa, reutilizável em mensagens depois de capturado.

Conectando com sistemas externos

Action / Custom action

Passo do fluxo que faz uma chamada de API para um sistema externo — a peça que chama o n8n.

Connection

Onde ficam guardadas as credenciais (API key, Basic, Bearer, OAuth 2.0).

Scenario

Condição dentro do bloco de integração para separar o que fazer conforme a resposta.

Fallback

Cenário padrão para quando nada mais bate — inclusive erro técnico e timeout.

Webhook (n8n)

ATUAL

Nó do n8n que gera uma URL única para receber chamadas HTTP do Zendesk — o ponto de entrada do workflow que consulta o ERP.

Regras e escalonamento

Handoff

Transferência da conversa do bot para um atendente humano, com o contexto já coletado.

Escalation block

Bloco do dialogue que faz o handoff, com mensagem e fila de destino configuráveis.

Messaging trigger

Regra automática de escalonamento por condição (ex.: sentimento negativo, cliente VIP).

Métricas e governança

Resolution rate

Problema resolvido de fato, sem escalar e sem o cliente voltar em 24-48h. A métrica que importa.

Deflection rate

Não virou ticket humano — mesmo que o cliente tenha desistido sem resolver nada.

BSAT

Satisfação específica com a interação com o bot.

CSAT

Satisfação geral do atendimento, não específica do bot.

Version history

Histórico de versões do dialogue — dá para reverter uma mudança publicada.
